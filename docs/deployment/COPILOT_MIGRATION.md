# Copilot Studio migration and identity proof

Microsoft documentation checked 2026-11-23: [connect an existing MCP server](https://learn.microsoft.com/en-us/microsoft-copilot-studio/mcp-add-existing-server-to-agent). It specifies Streamable transport and provides API-key and OAuth onboarding, including manual configuration and dynamic registration options. Actual tenant/channel behavior remains UNVERIFIED.

1. Record the working MVP connection's protocol/path, tool names, environment, owner and success correlation ID without credentials. The historical ConnectorOperationNotFound does not prove the current configuration is broken. Do not delete or overwrite the working agent connection.
2. In a separate staging agent/connection, add the stable approved HTTPS `/mcp` endpoint through the MCP onboarding wizard. Use manual OAuth as the initial Entra candidate; configure the tenant-approved client, audience/scopes, authorization/token/refresh endpoints and the exact callback URI the wizard supplies. Do not invent callback URLs or create tenant registrations during Phase 0.
3. Validate backend claims for a real employee call. Check issuer, tenant, audience, subject, client and scope/roles; log only approved identity metadata. Repeat as a second user and through the intended channel. Determine whether the connection is shared or per user. Never equate the chat display name with an authenticated backend user.
4. Test initialize, initialized notification, tools/list, tools/call, GET/DELETE session behavior, reconnect and expiry. Confirm both valid and denied tool/company results. Verify token refresh and revoked/expired credentials. Keep schema validation identical across transports.
5. Exercise company listing, bounded Day Book retrieval, review_vouchers and actual browser report download. Compare report company/range/IDs/totals and findings with the sanitized Tally source. The health tool only proves middleware liveness until a separate readiness check exists.
6. For a Claudally evaluation only, test dynamic discovery/DCR, public/confidential client mode, exact redirect URI matching, S256, code replay rejection, refresh rotation and all-method auth. An admin-secret-only registration policy can prevent automatic registration; choose a deliberate supported mode. Successful password OAuth does not prove Microsoft employee RBAC.
7. Package approved solution components and connection references in a managed Power Platform solution for later deployment. Each tenant owns credentials, consents and connections; no developer keys or temporary tunnel hostname in exported configuration.

If ConnectorOperationNotFound reappears, compare the agent's selected operation/connection reference to the deployed connector schema and solution version, check connection authorization and refresh tool discovery in staging, then capture a correlation ID. Do not blindly recreate production connectors or change Tally settings to fix a tool-registration error.

The current MVP OpenAPI is a REST specification with a temporary ngrok hostname. It is not evidence of a production MCP connection configuration. Public `/sse` aliases are unnecessary for the target, although Streamable HTTP itself may return SSE-encoded responses.
